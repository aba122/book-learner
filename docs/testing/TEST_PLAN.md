# 测试清单(按功能;每项通过打 ✓,失败记编号进 BUGS.md)

前提:`/Applications/book-learner.app` 为最新包(设置页「诊断」看提交号);codex 已登录;设置页导入了 whisper 模型(语音项才需要)。

## 1. 导入与地图
- [ ] 导入一本正常 EPUB(教材/方法论/人文各试一本)→ 进度逐章显示 → 生成地图 → 书名/作者来自书本身
- [ ] 导入 PDF → 向导只给转换命令不报错;Calibre 转换后导入成功
- [ ] 导入中途关掉 app 再打开 → 书架显示「导入未完成」→ 可删除后重导
- [ ] 地图页:编辑地图 → 上/下移、跳过/恢复、改模块名 → 确认定稿 → 设截止日 → 开始学习 → 回到今日页有任务
- [ ] 大书(≥ 300 页)导入耗时可接受;进度条不卡死

## 2. 每日学习闭环
- [ ] 今日页:任务顺序 重考 → 复习 → 新块;「专注」番茄钟能走、托盘倒计时、暂停/继续/结束、结束后统计有分钟
- [ ] 新块「开始」→ 阅读器学习模式 → 「开始费曼讲授」→ 发送复述 → 学生追问 → 结束讲授 → 评估卡(星级/薄弱点)→ 确认通过 / 暂不通过再学
- [ ] 通过后附加环节(教材:迁移应用题;方法论:情境化;人文:观点讨论)→ 整理并归档;「跳过」也能回今日
- [ ] 语音:🎙 → 录音计时/电平 → 停止 → 文本填入输入框可编辑 → 发送
- [ ] 第二天(或用测试日期):薄弱点重考进队列;通过的块按 1/3/7/14 天出现间隔复习;快问自动开场
- [ ] 落后两天不学 → 打开今日页弹「进度落后」→ 顺延 / 缩减两条路都能走
- [ ] 系统通知:到设置的提醒时间弹通知;晚间未完成提醒

## 3. 书架与多书
- [ ] 第二本书导入后为「已暂停」;切换主攻需确认;切换后明天队列按新书
- [ ] 标记为已学完 → 计划冻结、复习照常、不能再设为主攻
- [ ] 删除书 → 确认框 → 书消失、记忆库目录消失、`snapshots/` 有当日快照;删主攻书后需另选主攻

## 4. 阅读器
- [ ] 目录跳转、翻页、字号/主题/行高/缩进/覆盖出版方样式;关掉再开保留偏好与阅读位置
- [ ] 选中文字 → 四色高亮;书签;标记面板跳转与删除
- [ ] 学习模式:块范围下划线、起始定位到块(BL-001 修复后再验)

## 5. 终评、导出、数据
- [ ] 全部块通过 → 地图页「整书终评」→ 三轮作答 → 学习报告 → 书变已学完
- [ ] 设置 Obsidian 目录 → 书架「导出到 Obsidian」→ 文件在目标目录、Obsidian 里链接可点
- [ ] 设置页:立即快照;登记恢复 → 重启后生效;git 远程校验与推送(需先在终端配好凭据)
- [ ] 画像编辑保存;codex 路径填错有提示;语音模型导入/删除/选择

## 6. 稳定性
- [ ] Cmd+Q 与关窗:关窗只隐藏,托盘可恢复;Cmd+Q 时番茄钟结束并落分钟、快照更新
- [ ] 断网/codex 未登录时:提示可重试,不崩;重试能续跑
- [ ] 连续使用 1 小时无明显变慢;日志目录按天一个文件

## 范围外(不作为缺陷)
PDF 原生导入(用 Calibre 转);应用内下载 whisper 模型;Developer ID 签名与公证(首次打开需右键);霞鹜文楷内置;手动锚点校正 UI;画像「个人情境」AI 提取;地图页拖拽排序(现为上下移)。
