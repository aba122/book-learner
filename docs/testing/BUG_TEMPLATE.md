# Bug 报告模板

复制下面这段,填好发给 Claude(一句话 + 诊断包即可;能截图更好)。

```
编号:(留空,由台账分配)
版本:设置页「诊断」里的 git 提交(如 9986a50)/ 构建时间
时间:大约几点几分(对上日志)
在哪个页面:书架 / 地图 / 今日 / 阅读器 / 费曼 / 终评 / 统计 / 设置
我做了什么:(按顺序,越具体越好,例如"导入《X》选教材 → 编辑地图 → 确认定稿 → 设截止日 → 开始学习")
看到了什么:(原文抄错误提示;卡住就写"一直显示 XX 超过 N 分钟")
期望是什么:
能否复现:每次 / 偶尔 / 只出现一次
附件:诊断包 zip(`zsh ~/Developer/book-learner/docs/smoke/scripts/diag-bundle.sh` 生成到桌面)
```

**严重级**(由台账定,你也可以标):P0 数据丢失/打不开/主流程走不通;P1 功能错误但可绕过;P2 体验/文案/性能;P3 建议。

**不用报的**:范围外清单见 `docs/testing/TEST_PLAN.md` 末尾(PDF 原生导入、应用内下载模型、签名公证、霞鹜文楷、锚点手动校正、画像情境 AI 提取)。
